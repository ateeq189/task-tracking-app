# App Screenshots

Capture genuine screenshots from the configured, running app and save them in
this folder using these filenames:

- `login.png` — login screen
- `intern_home.png` — intern task list and progress bar
- `add_task.png` — add task form
- `admin_overview.png` — admin counts and task list
- `assign_task.png` — assign/edit task form
- `interns.png` — interns list and progress
- `reports.png` — reports charts and ranking table

Screenshots are not checked in yet. Do not include credentials, personal
information, or real users' private task data in screenshots.
